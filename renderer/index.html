Version 3.2.0 — December 21, 2024

🎨 Enhanced: Color Profile Preservation

  • ✅ NEW: exiftool integration! Extracts embedded DNG previews with color profiles intact
  • Preserves B&W rendering: DNGs with applied color profiles (B&W, film sims) render correctly
  • Three-tier processing: exiftool (best) → sips (good) → Sharp (fallback)
  • Faster & better: Embedded previews are quicker and respect camera settings
  • Optional: Install with brew install exiftool for best results

Version 3.1.0 — December 21, 2024

🎉 Major Feature: Full RAW/DNG Support

  • ✅ FIXED: All DNG files now work! Using macOS native sips for RAW conversion
  • Proper RAW Processing: Full RAW decoding (not just embedded previews)
  • All RAW Formats: DNG, CR2, NEF, ARW, ORF, RW2, RAF supported
  • Automatic Detection: App detects sips availability at startup
  • Smart Fallback: Falls back to Sharp's preview extraction if needed
  • No Dependencies: Uses built-in macOS tools

How It Works

  • Primary: Uses macOS sips to convert RAW to JPEG with best quality
  • Fallback: Sharp's embedded preview extraction (previous method)
  • Result: All your DNG files should load successfully!

Version 3.0.0 — December 21, 2024

What's New

  • 7 Aspect Ratios: Support for 3:2, 4:3, 16:9, 1:1, 2:3, 3:4, and 9:16 formats
  • Auto-Detect Aspect Ratio: Automatically analyze and select the best ratio for your images
  • Single-Sheet Mode: Fit all images on one sheet with three containment methods
  • Resize Thumbnail: Shrink thumbnails to fit all images on fixed canvas
  • Resize Sheet (Width/Height): Expand canvas width or height while maintaining thumbnail size
  • Dynamic Grid Optimization: Smart column/row calculation based on aspect ratio and image count
  • Distributed Spacing: Evenly spaced layouts with no wasted vertical space

Technical Improvements

  • Dynamic grid calculation engine with 4-7 column layouts based on aspect ratio
  • Three containment modes: resize-thumbnail, resize-sheet-w, resize-sheet-h
  • Smart thumbnail maximization algorithm for single-sheet mode
  • Aspect ratio parsing and decimal conversion system
  • Distributed vertical spacing for balanced layouts
  • Enhanced letterboxing/pillarboxing for all 7 aspect ratios
  • Grid parameters calculated once per sheet for better performance
  • Full backward compatibility with v2.0.0 default settings
