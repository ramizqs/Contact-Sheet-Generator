## ⚠️ Known Info

### Security Warning (Normal)
Users will see a warning on first launch because the app isn't code-signed. This is expected for apps distributed outside the Mac App Store.

**Solution:** Right-click → Open → Open (one time only)

### Harmless Console Warning
You might see a warning about `GNotificationCenterDelegate` - this is harmless and doesn't affect functionality.
