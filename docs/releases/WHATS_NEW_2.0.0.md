# What's New in Version 2.0.0 🎉

## Major New Features

### 📐 Resolution Settings
Choose your output resolution based on your needs:

| Resolution | Dimensions | Use Case |
|------------|------------|----------|
| **2K** | 2048 × 1782px | Screen viewing, digital proofing |
| **4K** | 4096 × 3564px | High-quality prints, portfolios |
| **6K** | 6144 × 5346px | Large format prints, galleries |
| **8K** | 8192 × 7128px | Ultra-high-res, museum quality |

All dimensions scale proportionally - fonts, spacing, margins, everything!

### 🔤 Complete Font Embedding
- **UI:** Kode Mono now displays in the application interface
- **Images:** Kode Mono renders in generated contact sheets
- **Zero Setup:** No font installation required
- **Universal:** Works in development and packaged app

### 📋 Enhanced Changelog
- Complete version history (1.0.0, 1.1.0, 2.0.0)
- Detailed feature lists for each version
- Known issues section for transparency
