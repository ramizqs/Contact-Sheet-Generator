## 🚀 What's New in 3.0.0

### Planned Major Features (Roadmap)
1. **Increased Text Contrast** - Enhanced readability in generated contact sheets
   - Improved visibility for printing and presentations
   - Better legibility in various viewing conditions

2. **Auto-Detection of Image Aspect Ratio** - Smart folder analysis
   - Automatically detect the most common aspect ratio in selected folder
   - Auto-selects appropriate aspect ratio from dropdown
   - Reduces manual configuration time

3. **Better Support for Image Aspect Ratios** - Mixed format handling
   - Improved handling of mixed aspect ratios within a single folder
   - Smart detection of multiple formats
   - Professional handling of edge cases

4. **Contact Sheet Sizing Options** - Flexible output dimensions
   - Letter format (8.5×11" at 300dpi)
   - A4 format (8.27×11.69" at 300dpi)
   - Square format (Instagram-friendly)
   - Custom dimensions
   - Resolution scaling integration with existing 2K/4K/6K/8K options

### Design Improvements ✨
- **Custom Black Background** for DMG installer window
  - Professional, sleek installation experience
  - 540×380 black background with retina support
- **Enhanced DMG Installer** with updated icon
- **Updated Version Info** throughout the application
